# BLE Hub Frontend MVP

Frontend inicial para BLE Hub con React + Vite + TypeScript.

## Instalación

```bash
cd frontend
cp .env.example .env
npm install
npm run dev
```

Por defecto espera la API en:

```text
http://localhost:8000
```

Si la API está en otra máquina:

```env
VITE_API_BASE_URL=http://IP_RASPBERRY:8000
```

## Vistas

- Dashboard
- Devices
- Events
- Rules
